# Security policy

This development preview has no supported stable releases yet. Do not use it to mutate production clusters. It does not read kubeconfig. Adapters and Go invariant code are trusted executable code; YAML files are data, not sandboxed programs.

Report vulnerabilities privately using GitHub private vulnerability reporting if enabled, otherwise request a private channel through https://sohamdev77.github.io. Do not disclose exploit details in public issues. No response SLA or bounty is promised. Include version, reproduction and impact with synthetic data only. Reports and snapshots may expose ConfigMap contents; redact before sharing.
