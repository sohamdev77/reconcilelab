# Code of Conduct

Be respectful, inclusive and technically constructive. Harassment, threats, discriminatory remarks, personal attacks and disclosure of private information are unacceptable. Debate code and assumptions, not people. Respect boundaries and accessibility needs.

Maintainers may edit or remove abusive contributions and restrict participation proportionately. Report concerns privately through the creator contact options at https://sohamdev77.github.io; do not publish private reports in issues. If no private contact is available, request a contact channel without sensitive detail. Maintainers should acknowledge reports, investigate fairly, protect confidentiality where practical and allow appeals through the same private channel. This policy applies in project spaces and public representation of the project.
